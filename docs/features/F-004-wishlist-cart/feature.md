# F-004 — Wishlist and cart

**Status:** Done — 2026-11-26 (approved: cart = shopping cart, guests allowed until checkout)

## Goal

Learners can save courses for later (wishlist) and buy several paid courses in one payment (cart).

## User stories

- As a visitor or learner, I tap a heart on any course card or course page to save it; I find saved courses on `/wishlist`.
- As a learner, I add paid courses to a cart, see the total (with a promo code) and pay once for all of them.
- Courses I already own, free courses, and courses included in my Pro plan never go in the cart.

## Out of scope

- Server-side sync across devices (no backend API docs yet).
- Plans and donations in the cart (they keep their own checkout).
